# Описание проекта: Bash-скрипт для работы с файлами и директориями

Данный проект представляет собой практическое задание по основам работы в командной строке Linux. Вам предстоит написать bash-скрипт, который автоматизирует ряд типовых операций с файлами и каталогами: создание, копирование, перемещение, удаление, поиск и вывод содержимого. 
Скрипт собирается из готового шаблона, состоящего из комментариев, под каждый из которых нужно подставить соответствующую команду. Результат работы скрипта должен быть строго определённым и не оставлять после себя временных файлов или каталогов.



## Актуальность и контекст

Bash — стандартная оболочка большинства Linux-систем, и умение писать скрипты для автоматизации повседневных задач — важный навык системного администратора, разработчика и DevOps-инженера. 
В рамках данного задания вы на практике примените основные команды файловой системы, научитесь комбинировать их с помощью конвейеров (`|`) и перенаправлений (`>`, `>>`), а также познакомитесь с принципами написания переносимых скриптов, которые не зависят от абсолютных путей.


## Цель работы

1. Закрепить знание базовых команд Linux: `cat`, `cd`, `chmod`, `cp`, `echo`, `find`, `grep`, `ls`, `mkdir`, `mv`, `rm`, `touch`.
2. Научиться писать исполняемые bash-скрипты с заданной последовательностью действий.
3. Отработать работу с относительными путями, переменными окружения и перенаправлением ввода-вывода.
4. Добиться точного соответствия выходных данных скрипта эталонному результату.



## Функциональные требования

Скрипт должен выполнять следующие действия (в порядке, заданном комментариями в шаблоне):

1. **Создание каталогов**  
   Создать иерархию директорий (например, `dir1`, `dir2`, `dir3/dir4`) с помощью `mkdir`.

2. **Создание файлов**  
   Создать пустые файлы командой `touch` в различных каталогах (например, `list.txt`, `summary.txt`).

3. **Копирование и перемещение**  
   Скопировать (`cp`) или переместить (`mv`) файлы между каталогами.

4. **Запись содержимого**  
   С помощью `echo` и перенаправления (`>`, `>>`) записать текстовые строки в файлы.

5. **Поиск и фильтрация**  
   Использовать `find` и `grep` для поиска файлов по имени или содержимому, а также для вывода отфильтрованных списков.

6. **Удаление**  
   Удалить (`rm`) ненужные файлы или каталоги (с опцией `-r` при необходимости).

7. **Вывод результатов**  
   Использовать `cat`, `ls` и `echo` для вывода на экран содержимого файлов и списков каталогов в нужном порядке.

8. **Завершение**  
   После выполнения всех операций скрипт должен вывести на консоль именно те строки, которые приведены в задании.

Важно: скрипт не должен использовать абсолютные пути (например, `/home/user/...`) – все пути должны быть относительными, чтобы скрипт можно было запускать в любой директории. По окончании работы скрипт не должен оставлять созданных файлов или каталогов (за исключением, возможно, временных, но задание подразумевает, что всё очищается). 
Однако эталонный вывод подразумевает, что скрипт выводит список файлов, которые существуют на момент вывода – значит, они должны быть созданы и не удалены до вывода.


## Структура проекта

```
.
├── task.sh          # основной исполняемый скрипт (шаблон с комментариями)
└── README.md        # описание проекта (данный файл)
```

Файл `task.sh` должен иметь права на выполнение (`chmod +x task.sh`) и запускаться командой `./task.sh` из любой директории.



## Технические детали реализации

- **Интерпретатор**: в первой строке скрипта указывается `#!/bin/bash` (или `#!/usr/bin/env bash`).
- **Комментарии**: каждая команда пишется после комментария, описывающего действие. Комментарии не удаляются и не перемещаются.
- **Переменные**: при необходимости можно использовать локальные переменные окружения (например, `VAR='значение'`), но они должны быть доступны только внутри скрипта.
- **Перенаправление**:
  - `>` – перезаписывает файл.
  - `>>` – дописывает в конец файла.
- **Конвейеры**: `|` используется для передачи вывода одной команды на вход другой (например, `ls | grep 'txt'`).
- **Кавычки**:
  - Одинарные кавычки (`'`) сохраняют буквальное значение всех символов.
  - Двойные кавычки (`"`) позволяют подстановку переменных (`$VAR`).
- **Относительные пути**: все операции выполняются в текущей рабочей директории; не используются пути, начинающиеся с `/`.



## Ожидаемый вывод

При успешном выполнении скрипт должен вывести в точности следующие строки (порядок и содержимое важны):

```
./dir2/list.txt
./dir3/dir4/list.txt
./dir1/summary.txt
empty
hello.sh
list.txt
Всем студентам, привет!
./dir1/summary.txt
./dir2/list.txt
./dir3/dir4/list.txt
```

Допускаются незначительные расхождения в форматировании (например, лишние пробелы), но в идеале вывод должен быть идентичным приведённому.



## Инструкция по запуску и проверке

1. Скопируйте шаблон скрипта в файл `task.sh`.
2. Вставьте необходимые команды после каждого комментария.
3. Дайте права на выполнение: `chmod +x task.sh`.
4. Запустите скрипт: `./task.sh`.
5. Сравните полученный вывод с эталоном.

Если вывод отличается, проанализируйте порядок действий – возможно, нарушена последовательность создания, копирования или удаления файлов.



## Рекомендации по разработке

- Внимательно читайте комментарии – они точно описывают, что должна делать каждая команда.
- Используйте `pwd` и `ls -R` для отладки структуры каталогов во время разработки.
- Для поиска файлов используйте `find` с опцией `-name` или `-type f`.
- Для вывода содержимого файлов применяйте `cat`.
- Не забывайте, что `mv` может использоваться как для переименования, так и для перемещения.
- Если команда требует подтверждения (например, `rm -r`), используйте флаг `-f` для принудительного выполнения без запроса.

Эти умения пригодятся не только в дальнейшем изучении Linux, но и в повседневной работе программиста, особенно при настройке окружения, развёртывании приложений и написании сборочных сценариев.
